# Makeover Run / DIY Renovation / Transformation Runner

## Overview

A runner game where a character (often worn down, messy, or in disrepair) runs down a corridor lined with transformation stations — hair salons, clothing racks, cosmetic counters, cleaning supplies, power tools. Running through each station triggers an instant visible transformation: torn clothes → stylish dress; dirty hair → perfect blowout; broken wall → painted accent wall. The "before" is shown prominently; the transformation is the payoff.

A parallel subgenre applies the same arc to rooms and homes rather than characters: a dilapidated room is "renovated" by running through improvement stations.

## Game Mechanics

### Character Makeover Variant
- **Setup:** Auto-runner corridor; character in "before" state; transformation stations on left and right
- **Control:** Swipe to steer toward desired stations
- **Feedback:** Each station triggers an instant character transformation — visual, often with sound effect
- **Win condition:** Reach the end in the "best" transformed state; sometimes a score or rating system
- **Fail condition:** Some variants have "negative" stations (muddy puddles, wrong choices) that revert progress

### Room / Home Renovation Variant
- **Setup:** Same runner format; the "character" is a room shown in disrepair
- **Stations:** Painting, flooring, furniture, lighting
- **Win condition:** Maximum renovation score; unlock narrative scenes of completed room
- **Meta loop:** Renovated rooms are revealed to a client or family; narrative reaction provides emotional payoff

### Match-3 Hybrid Variant
- **Project Makeover** and similar titles embed the transformation narrative in a match-3 core loop: puzzle-solving generates renovation resources, which fund the visible transformation
- This is the most commercially sophisticated implementation, using the transformation fantasy as motivational wrapper for a separate core mechanic

## What Makes It Appealing

### The Before/After Arc
Before-and-after transformation is one of the most powerful advertising structures ever devised. Before-and-after has sold beauty products, home improvement services, and fitness programs for a century. The mobile game version gamifies it: *you* run the transformation, *you* make the choices.

### The Cinderella Archetype
The worn-down-to-glamorous transformation arc is a deeply embedded narrative archetype. The ugly duckling → swan, rags to riches, Cinderella — these are among the oldest and most cross-culturally universal story structures. The runner game delivers this arc in 30 seconds, compressed but recognizable.

### Projection and Self-Improvement Desire
The makeover character functions as an avatar for the viewer's own transformation wishes. Players are not just watching a cartoon character get styled — they are projecting their own desire for renewal, improvement, or a fresh start onto the character.

### Contrast Sensitivity
The human visual system is extremely sensitive to before/after contrast. Transformation ads exploit low-level perceptual salience — the brain notices change automatically and intensely. A pristine result standing against a degraded "before" image generates a stronger aesthetic response than a pristine image alone.

### Agency Over Aesthetics
The choice of which stations to run through gives the player control over an aesthetic outcome. Autonomy over appearance — choosing your own look, your own room — satisfies psychological needs for self-determination. The game delivers a low-stakes context for aesthetic self-expression.

## Psychological Principles at Play

| Principle | Mechanism |
|---|---|
| **Cinderella archetype / transformation fantasy** | Rags-to-riches narrative structure triggers emotional engagement across virtually all demographics |
| **Projection and self-improvement desire** | The makeover character is an avatar for the viewer's own transformation wishes |
| **Contrast sensitivity** | Before/after visual contrast is maximally salient; the brain attends to change automatically and intensely |
| **Agency over appearance** | Choosing transformation stations satisfies autonomy needs around aesthetic self-expression |
| **Earned transformation** | Running through stations to "earn" the makeover adds agency to what would otherwise be passive spectatorship |

## Cross-Demographic Appeal

Makeover games are unusual in that their appeal genuinely crosses demographic lines:
- **Women 25–45** respond to character makeover narratives through self-projection and aesthetic interest
- **Men 30–50** respond to home renovation narratives through ownership and improvement instincts
- **Both** respond to the before/after contrast and the agency element

Project Makeover's collaboration with Netflix's *Queer Eye* demonstrated that the transformation narrative could support brand partnerships at scale — the game's emotional register matched the show's premise precisely.
